# Responsible-Use and Human-Review Checklist

- [ ] Only synthetic or sanitized datasets are used.
- [ ] Email, IP address and account ID are masked in screenshots and exports.
- [ ] No suspicious links are opened.
- [ ] No malware is downloaded or executed.
- [ ] No live accounts or networks are tested.
- [ ] Model outputs are treated as decision support, not proof.
- [ ] High-risk cases are escalated to an authorized security analyst.
- [ ] Conflicting model predictions trigger human review.
- [ ] Low-confidence results (below 0.70) trigger human review.
- [ ] No automatic punishment, disciplinary action or account blocking is performed.
- [ ] Raw identifiers and confidential institutional data are not uploaded to public repositories.
